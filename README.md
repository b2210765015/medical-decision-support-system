# Medical Decision Support System

A simple Python-based medical decision support system that manages patient records and provides probability-based treatment recommendations.

## Features
- Create, remove and list patient records
- Calculate disease probability based on diagnosis accuracy and disease incidence
- Recommend whether a treatment should be applied based on treatment risk
- File-based input and output handling

## Technologies
- Python
- File I/O
- Probability calculation
- Basic decision support logic

## How to Run
```bash
python main.py
```

Input commands should be placed inside `doctors_aid_inputs.txt`.
Output will be written to `outputs.txt`.
